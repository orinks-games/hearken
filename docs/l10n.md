# Translations

A Hearken game can ship translations as gettext PO files. Spoken lines stay
English in the source; a catalog turns finished lines into the player's
language before they are spoken. Lines with no match stay English.

## Getting started

1. Make a `lang` folder next to your game (or under the data folder).
2. Add one file per language, named by its code: `lang/es.po`, `lang/fr.po`.
3. Each entry is the English line, then its translation:

```po
msgid ""
msgstr ""
"Language: es\n"
"X-Language-Name: Spanish\n"
"X-Language-Autonym: Español\n"

msgid "New screen."
msgstr "Nueva pantalla."

msgid "It is {tod}."
msgstr "Son las {tod}."
```

4. Run the game. Once at least one catalog is present, Settings shows a
   Language row. Automatic follows the system locale; Left and Right pick a
   language. A file in `lang/` next to the program overrides a built-in
   catalog for the same code.

### Minimal code

Most games need no code beyond shipping the files. `Ctx::say` and
`say_event` translate automatically once a catalog is loaded at launch.
A new settings file starts on English.

To follow the system locale on a first launch instead:

```rust
impl Game for MyGame {
    fn default_language() -> &'static str {
        hearken::l10n::AUTO
    }
}
```

To embed catalogs in the binary instead of loose files:

```rust
impl Game for MyGame {
    fn translation_catalogs() -> &'static [(&'static str, &'static str)] {
        &[("es", include_str!("../lang/es.po"))]
    }
}
```

To force a language for one run, set `<PREFIX>_LANG` (for example
`HELLO_LANG=es`). To list lines that stayed English, set
`<PREFIX>_L10N_MISSES` to a file path.

### Fallback

- English (`en`) is the identity: no lookups.
- An unknown setting, a missing file, or a broken entry falls back to English.
- A sentence translates whole or not at all, so a player never hears one
  sentence mixed across languages. Partial catalogs only cost language, not
  a missing line.
- Place names and key names in `{holes}` stay as written.
- While Chinese or Japanese is active, the event pacer counts those
  characters at three times the weight of a Latin letter (then restores the
  game's ordinary weight when you switch away).

## Checking catalogs in CI

```rust
let issues = hearken::l10n::check_dir(std::path::Path::new("lang"));
assert!(issues.is_empty(), "{issues:?}");
```

`check_catalog` / `check_dir` catch unknown placeholders and parse errors.
They do not rewrite files, and they are thinner than a full extract/check
pipeline (no source-string scrape yet).

## File layout

| Path | Role |
| --- | --- |
| `lang/<code>.po` beside the program | Override / drop-in catalog |
| `<data dir>/lang/<code>.po` | Same, used when the program folder is not writable |
| `Game::translation_catalogs` | Optional built-in PO text |

Header fields `X-Language-Name` and `X-Language-Autonym` name the language
in Settings ("Spanish (Español)"). A code not on Hearken's built-in list is
still offered when its file is present. The Language row stays hidden until
at least one non-English catalog translates something.
